## 🚀 Quick Start

### Access the IDE
```
URL: /editor-enhanced?projectId=<PROJECT_ID>
```

### Key Shortcuts
- `Ctrl+Shift+P` / `⌘⇧P` - Command Palette
- `Ctrl+S` / `⌘S` - Save File
- `Ctrl+Shift+E` / `⌘⇧E` - Explorer
- `Ctrl+Shift+F` / `⌘⇧F` - Search
- `Ctrl+`` / `⌃`` - Terminal
- `Ctrl+K Z` / `⌘K Z` - Zen Mode
- `F5` - Start Debugging
- `F10` - Step Over
- `F11` - Step Into

### Common Tasks
1. **Create Snippet** → Left panel → Snippets → New
2. **Format Code** → Menu → Edit → Format Document
3. **Debug Code** → Set breakpoint → F5
4. **Search** → Ctrl+Shift+F
5. **Git Commit** → Left panel → Git → Enter message → Commit
